# アプリ画面設計

このアプリを構成する画面の一覧の存在と内容を定義しておく。
権限ごとに見られる画面が違うことに注意。
現段階ではレスポンシブデザインは考慮せずPCを前提とする。

## BUY権限向け画面

### ログイン画面

ログイン画面の詳細設計については`auth.md`を参照してください。

### メインページ（ホーム）
- ヘッダー：検索バー、買い物かごアイコン、ユーザーメニュー
- おすすめ商品一覧（タイル表示）
- 過去に購入した商品
- カテゴリ別商品表示
- フッター

### 商品検索結果画面
- 検索フィルター（価格範囲、カテゴリ等）
- 商品一覧（リスト/タイル切り替え可能）
- ソート機能（価格順、新着順等）
- ページネーション

### 商品詳細画面
- 商品画像（メイン+サブ画像）
- 商品名、価格、消費期限、説明文
- 数量選択
- 「カートに追加」ボタン
- 販売者情報

### 買い物かご画面
- カート内商品一覧（商品名、画像、単価、数量、小計）
- 数量変更・削除ボタン
- 合計金額表示
- 「レジに進む」ボタン

### 決済確認画面
- 注文内容確認（商品、数量、金額）
- 配送先住所選択/新規追加
- 配送日時指定
- 決済方法選択
- 「注文確定」ボタン

### 注文完了画面
- 注文番号表示
- 注文内容サマリー
- 「注文履歴を見る」ボタン

### マイページ
- ユーザー情報表示
- 注文履歴一覧（クリックで詳細表示）
- 住所管理（一覧・追加・編集・削除）
- ログアウトボタン

### 注文履歴詳細画面
- 注文番号、注文日時
- 商品詳細、数量、金額
- 配送先情報
- 配送状況
