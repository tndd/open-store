# 設計思想
- 配送ではなく取りに来てもらうという地元仕様の店舗
- 卸と配送のマージンを全て削ぎ落とす
    - 皆、スーパーの特売の数百円の割引のために何時間も列に並ぶ
    - ならば更なる割引のために１時間自転車で移動して品物を受け取る程度なら十分見込みがある


# アカウント作成の障壁
- アカウント作成は煩わしいものでパスワード管理も大変
- そこでユーザーはメールアドレスのみでログインまでを行うことができるようにする

## ユーザーのデフォルト設定
- デフォルトのユーザー名はメアドの@の前部分として設定される
- 配送先は**初注文の時に**入力をしてもらう形にする
- 登録を段階的に行わせることで、さらに登録障壁を下げる
